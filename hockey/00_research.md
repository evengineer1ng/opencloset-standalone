# Hockey Data Source Research

## Primary Data Sources

### NHL API (nhlapi.com / NHL.com)
- **Coverage**: Full NHL play-by-play, shifts, hits, blocks, shots, penalties
- **Depth**: Game-level events with timestamps, player IDs, zone data
- **Limitations**: No advanced metrics (RAPM, zone quality), no video
- **Cost**: Free tier available, paid tiers for bulk access
- **Verdict**: Primary source for event data

### Natural Language Notes
- **Coverage**: Scouting reports, qualitative assessments
- **Depth**: Subjective evaluations, intangibles, character notes
- **Limitations**: Unstructured, inconsistent formats
- **Verdict**: Secondary source for qualitative traits
