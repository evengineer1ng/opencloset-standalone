# QUICK FIX GUIDE: Races & Job Board Not Working on Loaded Saves

## The Problem
After loading a saved game:
- ❌ Races don't trigger (no pre-race prompts, instant replay/watch live both broken)
- ❌ Job board is empty (no AI team job listings)
- ❌ No free agents available to hire
- ❌ **Race/quali results don't display after completing a race** ⬅️ NEW!

## The Root Cause
**Save/load system was incomplete** - Several critical fields were never being saved or loaded:
- `free_agents` and `job_board` were initialized to empty on every load
- `_last_race_results` and `_last_race_contexts` were never saved, so results couldn't display

## The Solution

### For NEW Games (Created After This Fix)
✅ Everything works automatically - no action needed!

### For OLD Saves (Created Before This Fix)

**Option 1: Patch Your Existing Save** (Recommended)
```bash
python fix_save_markets.py saves/your_save.json
```
This adds empty market structures. The game will populate them naturally as you play.

**Option 2: Apply Morale Fix First** (If you also had morale issues)
```bash
# Fix morale baselines first
python fix_morale_baselines.py saves/your_save.json --boost

# Then fix markets
python fix_save_markets.py saves/your_save.json
```

## Troubleshooting

**"Job board still empty after loading patched save"**
- ✅ Expected! Advance time (a few ticks) to allow AI teams to post jobs
- Job generation happens during normal simulation

**"No free agents after loading patched save"**  
- ✅ Expected! Advance time to trigger world generation
- Free agents are generated by WorldBuilder during gameplay

**"Races still not triggering"**
- Check race schedule: `python check_race_state.py saves/your_save.json`
- Verify your next race tick
- Make sure you're advancing time (not paused)
- Check race_day_state is IDLE (not stuck in another phase)

**"Save file is huge after patching"**
- ❌ Should NOT happen - patched saves add minimal data
- If save is much larger, report as bug
